# KingPlayer 视频播放器

一个基于 Qt6、FFmpeg 和 SDL3 开发的高性能多媒体播放器，支持多种视频格式和高级播放功能。

## 🎯 项目概述

本人也是新手小白，该播放器仅仅是在本人学习过程中巩固所学，实现了简单的功能，欢迎指点。

## ✨ 主要功能

### 🎬 播放控制
- **基础播放控制**：播放、暂停、停止
- **进度控制**：拖拽进度条快速跳转
- **倍速播放**：支持 0.5x、1.0x、1.25x、1.5x、2.0x 等多种播放速度
- **音视频同步**：精确的音视频同步算法，确保播放流畅

### 🎵 音频处理
- **高质量音频输出**：基于 SDL3 音频系统
- **音频重采样**：支持不同采样率和格式的音频文件
- **变速播放**：使用 FFmpeg atempo 滤镜实现无损变速(暂时2x,1x,0.5x无损不变调，其他的需要叠加滤镜未实现)
- **音频时钟同步**：精确的音频时钟计算和同步机制

### 🖼️ 视频渲染
- **硬件加速渲染**：基于 SDL3 的高效视频渲染
- **多种视频格式支持**：通过 FFmpeg 支持主流视频格式
- **YUV 纹理渲染**：优化的视频帧显示性能

## 🏗️ 技术架构

### 核心组件

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   MainWindow    │────│     Player      │────│   SDL3/FFmpeg  │
│   (Qt6 GUI)     │    │  (核心播放器)    │    │   (多媒体库)     │
└─────────────────┘    └─────────────────┘    └─────────────────┘
         │                       │                       │
         │              ┌─────────────────┐              │
         └──────────────│  PacketQueue    │──────────────┘
                        │  FrameQueue     │
                        │  (队列管理)      │
                        └─────────────────┘
```

### 线程模型

- **主线程**：GUI 界面和用户交互
- **解封装线程**：读取和解析媒体文件
- **音频解码线程**：音频数据解码
- **视频解码线程**：视频数据解码
- **视频渲染线程**：视频帧显示和同步
- **音频播放线程**：音频数据播放和同步

### 关键类说明

- **Player**：核心播放器类，管理所有播放逻辑
- **PacketQueue**：线程安全的数据包队列
- **FrameQueue**：线程安全的帧队列
- **MainWindow**：主界面窗口，处理用户交互

## 🛠️ 构建说明

### 系统要求

- **操作系统**：Windows 11 
- **编译器**：MinGW 64-bit 或 MSVC 2019+
- **Qt 版本**：Qt 6.0+
- **CMake**：3.16+

### 依赖库

项目已包含预编译的依赖库：

- **FFmpeg 6.x**：音视频编解码库
  - libavcodec：编解码器
  - libavformat：格式处理
  - libavutil：工具函数
  - libavfilter：滤镜系统
  - libswresample：音频重采样
  - libswscale：视频缩放

- **SDL3**：跨平台多媒体库
  - 音频输出
  - 视频渲染
  - 事件处理

### 构建步骤

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd KingPlayer
   ```

2. **创建构建目录**
   ```bash
   mkdir build
   cd build
   ```

3. **配置项目**
   ```bash
   cmake .. -G "MinGW Makefiles"
   # 或使用 Qt Creator 直接打开 CMakeLists.txt
   ```

4. **编译项目**
   ```bash
   cmake --build .
   # 或在 Qt Creator 中按 Ctrl+B
   ```

5. **运行程序**
   ```bash
   ./KingPlayer.exe
   ```

## 🎮 使用说明

### 基本操作

1. **打开文件**：点击文件选择按钮选择视频文件
2. **播放控制**：使用播放/暂停按钮控制播放状态
3. **进度跳转**：拖拽进度条或使用快进/快退按钮
4. **倍速调节**：通过下拉菜单选择播放速度

### 快捷键

- **空格键**：播放/暂停
- **左箭头**：快退 15 秒
- **右箭头**：快进 15 秒
- **上/下箭头**：调节音量（暂未实现）

### 支持格式

可添加修改

## 🔧 技术特色

### 音视频同步算法

- **双时钟同步**：独立的音频时钟和视频时钟
- **自适应延迟**：根据时钟差异动态调整帧延迟
- **PTS 精确计算**：使用原始 PTS 避免滤镜影响
- **倍速同步**：变速播放时的精确时钟管理
